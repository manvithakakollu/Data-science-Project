Introduction

The dataset contains 12,700+ wine samples, each described by chemical properties and subjective quality ratings.
Key features include:

Alcohol content

Acidity levels

Sulfur dioxide content

Label appeal score (subjective quality)

❓ Problem Statement

The goal is to explore and clean the wine dataset, addressing issues such as:

Missing values

Outliers

Skewed distributions

The cleaned dataset will then be prepared for machine learning model development to better predict wine quality.
